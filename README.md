# PhotoStudio – Photography Portfolio

Modern, responsive photography portfolio website designed for professional photographers.

**Live Demo:** [photography-website-dusky.vercel.app](https://photography-website-dusky.vercel.app)

---

## Overview

PhotoStudio is a clean and elegant photography website focused on showcasing wedding, baptism, and event photography. Built with performance and smooth animations in mind.

## Features

- Fully responsive, mobile-first design
- Smooth page transitions and animations
- Dedicated sections for Weddings, Baptisms, and Events
- Gallery and contact/booking section
- Modern UI with Tailwind CSS

## Tech Stack

- **Framework:** Next.js
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel
